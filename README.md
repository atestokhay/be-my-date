# 💖 Be My Date?

A cute, interactive web project built to ask someone out with a playful retro design.

## ✨ Features
- **Runaway "No" Button:** A playful interaction where the "No" button glides away safely when hovered.
- **Interactive Flow:** Step-by-step experience from proposal to dinner choices and calendar scheduling.
- **Privacy-First:** Uses standard mail delivery (`mailto`) instead of a database.
